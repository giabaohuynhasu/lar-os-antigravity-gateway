Phase 7 — Bounded Retry + Decorrelated Jitter

Mục tiêu nên là:

MAX_REQUEST_BUDGET = 25s
MAX_HOPS            = 5
MAX_RETRIES         = 4

Điểm quan trọng: 25 giây là ngân sách toàn request, không phải 25 giây cho mỗi provider.

2. Decorrelated jitter

Không nên dùng:

Python
Chạy
delay = base * 2 ** attempt

vì năm account cùng nhận 429 sẽ tạo synchronized retry.

Dùng:

Python
Chạy
sleep = min(cap, random.uniform(base, previous_sleep * 3))

Ví dụ:

Python
Chạy
import random


def decorrelated_jitter(
    previous_delay: float,
    base: float = 0.25,
    cap: float = 3.0,
) -> float:
    upper = max(base, previous_delay * 3.0)
    return min(cap, random.uniform(base, upper))

1.92s

Như vậy năm account bị 429 sẽ không đồng loạt quay lại upstream cùng một thời điểm.

3. Bounded retry loop

Mình khuyên dùng deadline monotonic:

Python
Chạy
import time


REQUEST_BUDGET = 25.0
MAX_HOPS = 5
MAX_RETRIES = 4


async def dispatch_with_retry(request):

    deadline = time.monotonic() + REQUEST_BUDGET

    previous_delay = 0.25
    attempted = set()

    for hop in range(MAX_HOPS):

        remaining = deadline - time.monotonic()

        if remaining <= 0:
            break

        provider = await router.select_next(
            attempted=attempted
        )

        if provider is None:
            break

        attempted.add(provider.name)

        # Circuit breaker remains the final authority.
        if not await provider.circuit.allow_request():
            continue

        started = time.monotonic()

        try:
            result = await call_provider(
                provider,
                request,
                timeout=remaining,
            )

            latency_ms = int(
                (time.monotonic() - started) * 1000
            )

            await provider.circuit.record_success(
                latency_ms
            )

            telemetry.emit(
                kind=2,  # SUCCESS
                provider=provider.id,
                latency_ms=latency_ms,
            )

            return result

        except RetryableError as exc:

            latency_ms = int(
                (time.monotonic() - started) * 1000
            )

            await provider.circuit.record_failure(
                exc,
                latency_ms,
            )

            telemetry.emit(
                kind=3,
                provider=provider.id,
                latency_ms=latency_ms,
            )

            remaining = deadline - time.monotonic()

            if remaining <= 0:
                break

            if hop >= MAX_RETRIES:
                break

            delay = decorrelated_jitter(
                previous_delay
            )

            previous_delay = delay

            # Never sleep beyond request deadline.
            await asyncio.sleep(
                min(delay, remaining)
            )

        except Exception:
            # Non-retryable error.
            raise

    # All bounded hops exhausted.
    return await dispatch_tier4(
        request,
        deadline=deadline,
    )

Phase 7 + 10 khi ghép vào LAR-OS

Mình sẽ coi request lifecycle hoàn chỉnh như:

                 │ Client Request  │

                   25s Deadline

                 Health Score Rank
                          ↓
                 Circuit Admission
                          ↓
                 Provider Attempt

                 success       retryable
                   ↓               ↓
                 EMA          record failure
                   ↓               ↓
              telemetry       jitter
                   ↓               ↓

                                  │
                                  ↓

Một lưu ý cuối: nếu mục tiêu là hard cap 25s, hãy truyền remaining xuống tận HTTP/CDP/CLIProxy call ở mỗi hop, thay vì chỉ kiểm tra deadline bên ngoài. Nếu underlying call có thể treo 60s thì retry loop phía trên vẫn không cứu được hard bound.
